# Регламент проверки и заполнения данных фильма

Ты работаешь с базой хоррор-фильмов проекта «Хоррорейро». Твоя задача — автоматически проверять и заполнять следующие поля карточки фильма:

Год
Доп. жанры
Страны
Производство
Дистрибуция
Дистрибуция в России

Уже заполненные значения разрешено переписывать, если проверка показывает, что они ошибочны, неполны или основаны на агрегаторных данных без подтверждения.

Не изменяй остальные поля карточки, если это прямо не требуется задачей.

## 1. Общий принцип

Главный принцип: лучше меньше данных, но подтверждённых.

Не добавляй компании, страны, жанры или дистрибьюторов только для полноты. Каждое значение должно быть обосновано источниками и соответствовать роли, которую оно выполняло именно в этом фильме.

TMDb API и проставленные в карточке ссылки используй как точку входа для идентификации фильма и получения первичных данных, но не как единственный источник истины.

TMDb, IMDb и Letterboxd часто:

— смешивают production, distribution и sales;
— автоматически переносят жанры;
— добавляют страны по месту съёмок или компании технического обслуживания;
— используют производственный год вместо года коммерческого релиза.

Все спорные данные нужно перепроверять.

## 2. Идентификация фильма

Перед изменением полей убедись, что работаешь именно с нужным фильмом.

Сопоставь:

— TMDb ID;
— IMDb ID;
— Letterboxd URL;
— оригинальное название;
— год;
— режиссёра;
— основных актёров;
— синопсис.

Не смешивай ремейки, короткометражные версии, расширенные версии, фильмы с одинаковыми названиями и разные части франшизы.

Если ссылка ведёт на конкретную версию фильма, заполняй данные именно для неё.

## 3. Приоритет источников

Используй источники примерно в следующем порядке.

### Наиболее приоритетные

1. Официальный сайт фильма.
2. Официальный пресс-кит.
3. Финальные титры или официальный релизный биллинг.
4. Официальный сайт производственной компании.
5. Официальный сайт дистрибьютора.
6. Официальный каталог национального киноинститута.
7. Официальные пресс-релизы.
8. Карточки официальных кинотеатральных и цифровых релизов.

### Дополнительные надёжные источники

— национальные киноинституты;
— государственные реестры фильмов;
— Cineuropa;
— Crew United;
— The Numbers;
— Box Office Mojo;
— Variety;
— Deadline;
— Screen Daily;
— Film New Europe;
— фестивальные каталоги;
— официальные страницы Apple TV, Prime Video, Netflix, Shudder, Screambox, iQIYI, Youku и других платформ.

### Агрегаторы

— TMDb;
— IMDb;
— Letterboxd;
— Rotten Tomatoes;
— Metacritic;
— FilmAffinity;
— Кинопоиск;
— Кино Mail.

Агрегаторы можно использовать для поиска зацепок, но важные спорные решения нельзя основывать только на одной агрегаторной карточке.

Если источники расходятся, не усредняй данные механически. Выбирай вариант, который лучше подтверждён первичными источниками и соответствует рабочей логике базы.

## 4. Поле «Год»

Год фильма определяется по году первого подтверждённого публичного коммерческого релиза.

Учитываются:

— кинотеатральный прокат;
— официальный платный публичный показ вне фестиваля;
— TVOD-релиз;
— VOD-релиз;
— платный стриминговый релиз;
— DVD или Blu-ray;
— официальный коммерческий телевизионный релиз.

Не считать основанием для года:

— фестивальные показы;
— закрытые показы;
— индустриальные показы;
— показы для прессы;
— тестовые показы;
— production year;
— copyright year;
— дату завершения съёмок или постпродакшена.

Пример:

Фестивальная премьера — 2024 год.
Первый коммерческий VOD-релиз — 2025 год.
Поле «Год» = 2025.

Платный публичный премьерный показ вне фестиваля можно считать коммерческим релизом, если билеты официально продавались широкой публике.

Если коммерческий релиз ещё не состоялся, но официально объявлена конкретная дата будущего релиза, можно использовать год этой даты.

Если есть только фестивальные показы и отсутствует подтверждённый коммерческий релиз или его официальная дата, не угадывай год. Не переписывай поле без достаточного основания.

В поле записывается только четырёхзначный год.

## 5. Поле «Доп. жанры»

Поле «Доп. жанры» содержит дополнительные общие жанры помимо базового жанра «Ужасы».

Не добавляй в это поле «Ужасы» ни при каких обстоятельствах: для каталога «Хоррорейро» этот жанр считается базовым для всех фильмов по умолчанию.

Если подтверждённые источники показывают, что конкретный фильм вообще не относится к хоррору, не пытайся исправить это через «Доп. жанры» и не удаляй фильм из базы автоматически. Добавь его в отдельный список «Фильмы без подтверждённого хоррор-статуса» в журнале проверки, чтобы владелец базы принял решение вручную.

Допустимый основной набор:

Триллер
Детектив
Фантастика
Фэнтези
Комедия
Драма
Мелодрама
Боевик

Новые жанры не добавляй без отдельного решения по структуре базы.

Не копируй все жанры из TMDb, IMDb, Letterboxd или Rotten Tomatoes автоматически.

### Триллер

Не добавляй «Триллер» только потому, что фильм обозначен как Horror / Thriller.

Добавляй, если есть самостоятельная триллерная структура:

— преследование;
— борьба за выживание;
— заговор;
— охота;
— серийный убийца;
— психологическая интрига;
— постоянный саспенс как отдельный двигатель сюжета;
— криминальная угроза;
— ограниченная временем смертельная ситуация.

Если напряжение полностью является частью обычной хоррор-механики, «Триллер» не добавляй.

### Детектив

Mystery не означает автоматический жанр «Детектив».

Добавляй «Детектив», если есть:

— расследование;
— поиск пропавшего человека;
— сбор и изучение улик;
— whodunnit;
— раскрытие старой тайны;
— изучение записей, документов или свидетельств;
— последовательный поиск ответа;
— puzzle-структура.

Не добавляй «Детектив», если зрителю просто долго не объясняют происходящее.

### Фантастика

Добавляй «Фантастика», если научно-фантастический механизм является самостоятельной основой фильма:

— технологии;
— эксперименты;
— мутации;
— космос;
— инопланетные существа;
— временные или пространственные аномалии;
— искусственный интеллект;
— биологическая угроза;
— научно объясняемый монстр;
— постапокалиптическая или антиутопическая реальность.

Не добавляй «Фантастика» автоматически из-за вируса, огромного животного, мутанта или необычной аномалии, если механизм не раскрыт и не является жанровой опорой.

### Фэнтези

Не добавляй «Фэнтези» из-за любого сверхъестественного элемента.

Призрак, демон, проклятие, одержимость, вампир или религиозная мистика сами по себе не означают жанр «Фэнтези».

Добавляй, если есть выраженная:

— сказочная структура;
— мифологическая реальность;
— фольклорный мир;
— dark fantasy;
— магический мир;
— фантастическое приключение;
— авторская сказка.

### Комедия

Добавляй «Комедия», если комедийный тон проходит через значительную часть фильма:

— horror comedy;
— black comedy;
— parody;
— satire;
— slapstick;
— романтическая хоррор-комедия.

Не добавляй жанр из-за нескольких шуток или ироничных сцен.

### Драма

Не добавляй «Драма» только потому, что у героя есть травма, семья, утрата или тяжёлое прошлое.

Добавляй, если драматический конфликт является самостоятельной частью жанровой структуры:

— семейная драма;
— отношения родителей и детей;
— кризис брака;
— переживание утраты;
— социальный конфликт;
— психологическое разрушение героя;
— длительное развитие отношений между персонажами.

### Мелодрама

Добавляй только при центральной романтической линии.

Любовные отношения должны быть одним из основных двигателей сюжета, а не второстепенной линией.

### Боевик

Action в агрегаторе не означает автоматический жанр «Боевик».

Добавляй, если фильм содержит регулярные:

— драки;
— перестрелки;
— погони;
— боевые столкновения;
— спасательные операции;
— масштабные атаки;
— monster-action-сцены.

Если в фильме есть одна финальная схватка, этого недостаточно.

### Фильмы, которые фактически не являются хоррорами

Если фильм находится в базе хорроров, но проверка показывает, что хоррор-иконография не формирует основной жанр, не пытайся компенсировать это добавлением лишних дополнительных жанров.

Зафиксируй такой случай в отдельном списке «Фильмы без подтверждённого хоррор-статуса» в журнале проверки для ручного рассмотрения.

## 6. Поле «Страны»

В поле записываются страны производства, а не страны:

— дистрибуции;
— съёмок;
— постпродакшена;
— финансирования;
— международных продаж;
— фестивальных показов;
— налоговых льгот.

Страну можно добавить, если подтверждено хотя бы одно из условий:

1. Фильм официально заявлен как копродукция этой страны.
2. В фильме участвует полноценная production или co-production company из этой страны.
3. Национальный киноинститут или официальный пресс-кит прямо называет страну страной производства.
4. Компания из этой страны выполняла основную физическую производственную роль, а не только сервисную поддержку.

Не добавляй страну только потому, что:

— там проходили съёмки;
— фильм получил tax credit;
— участвовала film commission;
— работала production service company;
— компания указана как in association with;
— компания занималась постпродакшеном;
— компания была sales-агентом или дистрибьютором;
— там находится материнская компания релизёра.

Если production-компания является формальным проектным юрлицом, проверяй реальную производственную принадлежность.

Названия стран записывай на русском языке.

Если стран несколько, соблюдай логичный порядок:

1. основная страна производства;
2. страны полноценной копродукции.

## 7. Поле «Производство»

В поле включаются только компании или лица, которые непосредственно занимались производством фильма.

Допустимые роли:

— production company;
— co-production company;
— physical production company;
— основной авторский продюсер, если отдельная компания отсутствует и производство официально указано на его имя.

Максимум — 5 значений.

Не переносить в производство:

— дистрибьюторов;
— sales-компании;
— sales agents;
— платформы;
— телеканалы;
— фонды;
— film commissions;
— налоговые программы;
— организации поддержки;
— financiers, если их роль ограничена финансированием;
— production support;
— production services, если это только локальное обслуживание;
— компании постпродакшена;
— правообладателей, не участвовавших в производстве;
— фестивали;
— каталоги;
— компании с формулировкой presents;
— компании с формулировкой in association with;
— компании с формулировкой in collaboration with;
— компании с формулировкой with the participation of;
— компании с формулировкой with the support of.

Пример биллинга:

Paramount Pictures presents
in association with Domain Entertainment
an 18Hz production

В поле «Производство» записывается:

18Hz Productions

Paramount Pictures и Domain Entertainment не добавляются.

### Проверка двойной роли

Если одна компания указана и в производстве, и в дистрибуции, это возможно, но требует отдельного подтверждения.

Не считай двойную роль доказанной только потому, что компания присутствует в двух разделах агрегатора.

### Порядок компаний

Сначала указывай:

1. основную production company;
2. основных сопродюсеров;
3. значимые physical production companies.

Младших копродюсеров можно не включать, если они не важны для связей внутри базы.

## 8. Поле «Дистрибуция»

Поле должно содержать одного основного дистрибьютора.

Приоритет:

1. основной дистрибьютор на домашнем рынке страны производства;
2. если домашний релиз отсутствует — первый подтверждённый коммерческий релизёр;
3. если классического дистрибьютора нет — компания самостоятельного релиза;
4. если и она не установлена — первая официальная коммерческая платформа.

Не записывай российского дистрибьютора в это поле.

### Домашний рынок

Основным считается дистрибьютор в стране производства или на главном домашнем рынке фильма.

Если фильм является копродукцией, выбирай релизёра на основном производственном рынке.

Если нормального домашнего релиза не было, используй первого подтверждённого коммерческого дистрибьютора на другой территории.

### Классический дистрибьютор важнее платформы

Если фильм сначала появился на платформе, но позднее выясняется, что права приобрёл классический дистрибьютор или релизный лейбл, в поле ставь классического дистрибьютора.

Платформу можно использовать только при отсутствии:

— подтверждённого дистрибьютора;
— релизного лейбла;
— правообладателя коммерческого выпуска;
— компании самостоятельного релиза.

### Sales-компания не равна дистрибьютору

Не записывай international sales agent в поле «Дистрибуция», если компания только продаёт права другим территориям.

Sales-компания подходит только тогда, когда подтверждено, что она сама осуществила коммерческий релиз.

### Саморелиз

Если фильм самостоятельно выпустила производственная компания, можно указать её же в дистрибуции.

В журнале проверки отметь, что это self-release, а не классический сторонний прокатчик.

### Релизные бренды и материнские компании

Используй наиболее конкретный подтверждённый релизный бренд.

Пример:

Magnet Releasing предпочтительнее Magnolia Pictures, если фильм официально выпущен именно лейблом Magnet.

RLJE Films предпочтительнее общего корпоративного названия IFC Entertainment Group, если релиз проходил через RLJE.

ITN Studios и ITN Distribution в релизном контуре унифицируй как:

ITN Distribution

## 9. Поле «Дистрибуция в России»

В поле записывается подтверждённый российский прокатчик, цифровой релизёр или локальный правообладатель.

Приоритет:

1. официальный российский кинотеатральный дистрибьютор;
2. официальный российский цифровой дистрибьютор;
3. официальный правообладатель русскоязычного релиза;
4. официальный дистрибьютор русскоязычной версии в СНГ или Казахстане;
5. легальная российская платформа — только если отдельный правообладатель не установлен.

### Обязательная дополнительная проверка

Всегда выполняй поиск по русскому названию фильма в сообществе VK «Официальный дубляж»:

https://vk.com/dubbingofficial

Это один из приоритетных источников по российским дистрибьюторам и заказчикам официального дубляжа.

Ищи по:

— официальному русскому названию;
— альтернативному русскому названию;
— оригинальному названию;
— названию без подзаголовка;
— названию франшизы и номеру части.

Если публикация сообщества прямо называет российского дистрибьютора или заказчика дубляжа, учитывай это как сильное подтверждение.

Дополнительно проверяй:

— официальный сайт российского дистрибьютора;
— каталог дистрибьютора;
— Кинобизнес;
— ПрофиСинема;
— официальный трейлер;
— прокатное удостоверение;
— кинотеатральные расписания;
— Film.ru;
— Кино Mail;
— Кинопоиск;
— Иви;
— Okko;
— Wink;
— Кинопоиск HD;
— Start;
— Premier;
— официальные страницы релиза в Казахстане и СНГ.

### Россия и СНГ

Если официального релиза в России не было, но фильм вышел:

— в Казахстане;
— в странах СНГ;
— на соседней территории;
— с официальным русским дубляжом;

можно указать соответствующего дистрибьютора.

В журнале проверки обязательно отметить:

«Не российский прокатчик в узком смысле; дистрибьютор официальной русскоязычной версии для Казахстана/СНГ».

### Платформы

Иви, Okko и другие платформы можно указывать только если:

— официальный коммерческий релиз подтверждён;
— отдельный локальный дистрибьютор или правообладатель не найден;
— платформа действительно является стороной релиза, а не просто одной из нескольких витрин.

Не выбирай платформу только потому, что фильм доступен в её каталоге.

Сначала проверь, не указан ли в титрах, описании, трейлере или релизных материалах реальный правообладатель.

## 10. Работа с TMDb API

Используй TMDb API для получения:

— названия;
— оригинального названия;
— production_companies;
— production_countries;
— genres;
— release_dates;
— external_ids;
— альтернативных названий;
— информации о цифровых и кинотеатральных релизах, если она доступна.

Но не записывай значения в базу напрямую без проверки.

### production_companies

Каждую компанию из TMDb нужно проверить по внешним источникам.

Не считать production-компанией автоматически.

### production_countries

Проверяй, не возникла ли страна из-за:

— места съёмок;
— сервисной компании;
— постпродакшена;
— налоговой программы;
— дистрибутора.

### genres

Не переносить жанры автоматически.

Применять правила поля «Доп. жанры».

### release_dates

Сравнивать:

— фестивальные даты;
— premiere;
— theatrical;
— digital;
— physical;
— TV.

Для поля «Год» использовать первую подтверждённую публичную коммерческую дату, а не первую дату в массиве TMDb.

## 11. Перезапись существующих полей

Разрешено переписывать уже заполненные поля.

Перезаписывай значение, если:

— найден более надёжный источник;
— компания указана с неверной ролью;
— дистрибьютор на самом деле является sales-компанией;
— платформа ошибочно указана вместо классического дистрибьютора;
— страна добавлена из-за места съёмок;
— год взят по фестивальной премьере;
— жанр перенесён автоматически;
— российский дистрибьютор не подтверждён;
— найден официальный российский релизёр.

Не сохраняй ошибочное старое значение только потому, что поле уже заполнено.

Перед перезаписью зафиксируй старое и новое значения в журнале изменений.

## 12. Уровень уверенности

Для каждого изменённого поля внутренне оценивай уверенность:

Высокая
Средняя
Низкая

### Высокая

Есть официальный источник или несколько независимых надёжных подтверждений.

### Средняя

Есть убедительные вторичные источники, но отсутствует прямой официальный документ.

### Низкая

Есть только агрегаторы, косвенные признаки или противоречивые сведения.

Поля с низкой уверенностью не заполняй автоматически, если значение может существенно исказить базу.

Передавай такие случаи на ручную проверку.

## 15. Финальный алгоритм

Для каждого фильма:

1. Получи данные карточки и все проставленные ссылки.
2. Определи точный TMDb ID.
3. Получи TMDb details, external IDs, release dates, genres, production companies и production countries.
4. Сопоставь фильм с IMDb и Letterboxd.
5. Проверь год первого коммерческого релиза.
6. Проверь, подтверждается ли хоррор-статус фильма. Если нет, добавь фильм в отдельный список для ручного решения и не компенсируй это дополнительными жанрами.
7. Проверь каждый дополнительный жанр по сюжету и официальному позиционированию. Не добавляй «Ужасы» в «Доп. жанры».
8. Проверь каждую страну как страну реального производства.
9. Раздели production, distribution, sales, financing и support.
10. Определи основного домашнего дистрибьютора.
11. Проверь российский релиз по официальным источникам.
12. Обязательно выполни поиск по русскому названию в VK-сообществе «Официальный дубляж».
13. Сравни новые значения с текущими.
14. Перепиши ошибочные или менее точные значения.
15. Не изменяй остальные поля.
16. Сохрани журнал изменений и использованные источники.
17. Случаи с низкой уверенностью передай на ручную проверку.

Главное правило: не доверяй одному агрегатору и не заполняй поля механически. Каждое значение должно отражать реальную роль компании, реальную страну производства, самостоятельный жанровый слой или подтверждённый коммерческий релиз.
